# Claude Code を特定のMCPサーバー設定で起動した場合と CLI で使う場合の違い

以下は、**「外部クライアントから Claude Code を MCP サーバーとして使う場合」**と、**`claude` を直接叩く CLI 利用**の比較を、**使える機能の有無**に注目して整理したものです。

> 注記  
> ここでの「MCPサーバーとして使う」は、Claude Code を他の MCP 対応クライアントからツール提供側として利用するケースを想定しています。実際に使える範囲は、接続先ホストの実装や権限処理に依存するため、表中の「△」は **環境依存** を意味します。

## 比較表

| 機能 | MCPサーバー経由で Claude Code を使う | CLIで Claude Code を使う | 補足 |
|---|---|---|---|
| コード読取り・検索（Read / Grep / Glob 相当） | ○ | ○ | 中核機能なので両方で使えることが多い |
| ファイル編集・書込み | ○ | ○ | Claude Code の主機能なので両方で使えることが多い |
| Bash / shell 実行 | ○ | ○ | ただし MCP 経由ではホスト側の許可UIや制限に左右されやすい |
| Git操作支援 | △ | ○ | MCP経由でも Bash 経由で可能なことは多いが、CLI のほうが一体感が強い |
| Claude Code の対話型 TUI | × | ○ | 端末UIそのものは CLI 専用 |
| スラッシュコマンド（`/help`, `/model`, `/mcp`, `/permissions` など） | × | ○ | MCP 経由では通常、ツール呼び出しだけが見える |
| `/resume` などのセッション再開 | × | ○ | 会話履歴は MCP ホスト側が持つことが多い |
| `/usage`, `/stats`, `/context`, `/doctor` | × | ○ | これらは CLI アプリの管理・可視化機能 |
| 音声入力 / voice mode | × | ○ | CLI 本体の対話機能寄り |
| キーボードショートカット（Ctrl系、TUI操作） | × | ○ | 当然ながら CLI のみ |
| 許可ダイアログ・権限管理 UI | △ | ○ | MCP 経由ではホスト側 UI に置き換わるか、簡略化される |
| `/mcp` での MCP 接続管理 | × | ○ | CLI では MCP クライアントとしての管理機能がある |
| Claude Code をさらに外部 MCP サーバーへ接続 | △ | ○ | Claude Code サーバープロセス側設定しだい。多段構成は複雑になりやすい |
| プラグイン / skills / hooks の管理 | △ | ○ | 読み込まれていれば効く可能性はあるが、管理UIは基本 CLI 前提 |
| 背景タスク / サブエージェントの直接操作 | △ | ○ | 内部では使えても、MCP 経由では見え方が限定されやすい |
| Plan mode や計画レビュー UI | × | ○ | これは CLI / IDE 統合側の体験に近い |
| IDE や LSP との深い連携 | △ | ○ | MCP ホストが別途補う場合もあるが、Claude Code 本体の統合体験は CLI 側が強い |
| JSON 出力・ヘッドレス自動化（`-p`, `stream-json` など） | × | ○ | これは明確に CLI 運用向け |
| ホスト依存性 | 高い | 低い | MCP 経由はホスト実装にかなり依存 |
| Claude Code 本来の“全部入り”体験 | × | ○ | フル機能を使いたいなら CLI |

## 要点

差の本質は次のとおりです。

### MCP経由

Claude Code の **「ツール実行エンジン部分」** を、他のクライアントに埋め込んで使う形に近いです。  
そのため、**ファイル操作・検索・編集・bash** のような実務コアは使えても、**TUI、スラッシュコマンド、usage 表示、resume、voice、管理画面系** は薄くなるか消えます。

### CLI直使用

Claude Code の **「エージェント機能 + 端末アプリ機能」** を丸ごと使えます。  
Claude Code らしさを最も強く感じるのはこの使い方です。

## 使い分けの目安

| 目的 | 向いている方 |
|---|---|
| 他の MCP 対応クライアントの中で Claude Code の編集・実行能力だけ使いたい | MCP経由 |
| Claude Code の機能を全部使いたい | CLI |
| セッション管理、権限管理、`/mcp`、`/resume`、`/usage` まで含めて使いたい | CLI |
| 自前 UI や別エージェント基盤に Claude Code の能力を組み込みたい | MCP経由 |

## まとめ

一言でいうと、

- **MCP経由** は「Claude Code の中身の一部を借りる」形
- **CLI** は「Claude Code そのものを使う」形

です。

Claude Code のフル機能を前提に使うなら CLI が向いており、既存の MCP 対応環境へ Claude Code の能力を埋め込みたいなら MCP 経由が向いています。

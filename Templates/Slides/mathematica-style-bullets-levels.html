Source-First ingest ― 取り込みパイプライン
各 source を5フェーズで取り込む
Resolve―URL / arXiv ID / ローカルパスを正規化し source ID を決定
Fetch―raw bytes を raw/by-hash/sha256-<hash> に保存（内容ハッシュで dedup）
同一内容は AlreadyCurrent として再取得しない
Parse―ページ単位でテキスト抽出（PDF は3種の OCR backend で fallback）
Index―meta/sources・meta/snapshots に deterministic な JSON で記録
Hook―NBAccess hook (P1〜P4) 経由で ClaudeAttach / Orchestrator に通知
版固定と再現性
生成物の metadata には、必ず pinned version と snapshot hash を残す。
Floating source―arXiv:2401.01234（最新版を指す）
Pinned source―arXiv:2401.01234v2（この生成・再現に使った厳密な版）
